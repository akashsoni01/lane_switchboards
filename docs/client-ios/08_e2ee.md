# E2EE (iOS)

Wire/crypto live in Rust (`docs/messenger/10_e2ee.md`). iOS owns pickle
storage, feature flags, and UX (safety numbers, export/import).

## Feature flags

| Flag | Default | Notes |
|------|---------|-------|
| `E2EE_ENABLED` | **on** (Release + staging) | DEBUG may override via `UserDefaults` |
| `DEBUG_PLAINTEXT_FALLBACK` | off | DEBUG only; never compiled into Release |

When E2EE is on and ready, 1:1 / group sends use encrypted paths. Local SQLite
still stores **plaintext** for the user’s own UI (standard messenger model).

## Boot

```text
connect → LoginAck → SyncComplete
  → E2eeService.ensureReady(deviceId)
      load Keychain/Application Support pickle
      or generate new device
      → publish one-time keys
```

## 1:1

```text
send: pending row → encrypt (Olm) → FunXMPP ChatMessage (opaque body)
recv: body bytes → decrypt → upsert plaintext (or "🔒 Unable to decrypt")
```

Group session key shares arrive as 1:1 ciphertext; the kit imports them and
does **not** show a chat bubble.

## Groups (Megolm)

```text
create / add member
  → create_group_session
  → distribute_group_key (Olm-wrapped share to each member)
send: encrypt_group → GroupMessage
recv: decrypt_group
```

## Safety numbers

`E2eeSafety.number(local, remote)` — stable fingerprint (order-independent).
Reachable from the chat lock menu. UI warns that screenshots can leak the
fingerprint.

## Pickle

| Store | Role |
|-------|------|
| Keychain `e2ee_pickle` | Primary |
| `Application Support/LaneMessenger/e2ee.pickle` | Mirror for backup/export |

Export/import use a **user passphrase** (settings sheet). Automatic device
pickle uses a local passphrase so restarts restore the same identity without
prompting.

## Threat model (UI notes)

See also [`docs/messenger/11_security_review.md`](../messenger/11_security_review.md).

- Server sees public keys and opaque ciphertext only (when E2EE path is used).
- Compromised device Keychain can expose the account pickle.
- Safety number changes after a new device publish — prompt users to re-verify.
- DEBUG plaintext fallback is for local gateway demos only.

## FFI (production XCFramework)

| C API | Purpose |
|-------|---------|
| `lane_e2ee_generate` / `import_pickle` | Device lifecycle |
| `lane_e2ee_publish` | Key directory |
| `lane_send_encrypted_chat` / `lane_decrypt_chat` | 1:1 Olm |
| `lane_e2ee_create_group_session` / `distribute_group_key` | Megolm setup |
| `lane_send_encrypted_group` / `lane_decrypt_group` | Group send/recv |
| `lane_e2ee_safety_number` | Fingerprint |

Kit smoke tests use `MockE2eeBackend` (reversible markers) so they run without
the native library. Link `LaneMessengerFFI` for real vodozemac.
