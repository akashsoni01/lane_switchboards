# E2EE (FFI)

Crypto stays in Rust (`vodozemac`). Do **not** ship a second Olm stack.

| API | Notes |
|-----|-------|
| `E2eeHandle::generate` | Fresh identity |
| `publish` | Identity + OTKs to key directory |
| `send_encrypted_chat` / `decrypt_chat` | Olm 1:1 |
| `create_group_session` / `distribute_group_key` / `send_encrypted_group` | Megolm |
| `try_import_group_key` | On inbound chat before treating as plaintext |
| `safety_number` | Order-independent |
| `export_pickle` / `import_pickle` | Account only; re-establish sessions after import |

Passphrase → 32-byte key via SHA-256 (prefer Argon2/scrypt in production hosts).
Store pickles in Keychain / Keystore — never sync to iCloud/Drive by default.

See [`docs/messenger/10_e2ee.md`](../messenger/10_e2ee.md) and
[`11_security_review.md`](../messenger/11_security_review.md).
